# Пример 03 — EXTI и кнопка

Это заготовка практической работы для STM32F407 + STM32CubeIDE + HAL C.

## Настройка в CubeMX
1. Выберите GPIO, реально подключённый к кнопке, и назначьте режим GPIO_EXTI.
2. Для кнопки, замыкающей вход на GND при внешней или внутренней подтяжке вверх, выберите Falling edge и Pull-up.
3. Включите соответствующую линию в NVIC.
4. Сгенерируйте код и проверьте IRQ-обработчик в stm32f4xx_it.c.

## Код пользовательской части

В секции USER CODE глобальных переменных:

```c
volatile uint8_t buttonEvent = 0;
```

В пользовательской части main.c:

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == BTN_Pin)
    {
        buttonEvent = 1;
    }
}
```

В основном цикле:

```c
while (1)
{
    if (buttonEvent != 0)
    {
        buttonEvent = 0;
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
    }
}
```

Замените BTN_Pin, LED_GPIO_Port и LED_Pin именами, созданными для вашего проекта в CubeMX. Не предполагайте, что определённый вывод подключён к светодиоду: сверьтесь со схемой конкретной платы.

Это кодовые фрагменты для переноса в проект, а не готовый STM32CubeIDE-проект: файл .ioc и разводка платы не включены.
