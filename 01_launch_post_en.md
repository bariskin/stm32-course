# LinkedIn launch post — English

I'm starting an open educational series on STM32F407.

The course is for C programmers who want to get started with embedded development on STM32. Each lesson will include:
- clear diagrams of the MCU architecture and peripherals;
- C examples using STM32 HAL;
- practical exercises for STM32CubeIDE;
- common pitfalls and review questions.

We start with the Cortex-M4 core, memory, GPIO, and program startup, then move on to interrupts, timers, UART, DMA, ADC, and FreeRTOS.
