# Publication checklist / Чек-лист публикации

## Before publishing
- [ ] Confirm exact MCU part number and development board.
- [ ] Review every technical claim and code example.
- [ ] Check that diagrams are legible and have captions / alt text.
- [ ] Remove secrets, credentials, private paths, and unrelated project files.
- [ ] Check third-party library and image licenses.
- [ ] Choose a repository license; MIT is included as a starter for original materials, but confirm it matches your intent.
- [ ] Add the final GitHub repository URL to both LinkedIn drafts.

## GitHub — first publication
1. Sign in to GitHub and create a new repository named `stm32-course`.
2. Choose Public if you want the course to be openly accessible.
3. Do not initialize with duplicate README/license files if uploading this prepared folder with those files already included.
4. Upload the contents of this folder (not the ZIP file itself) through the web interface, or use GitHub Desktop.
5. Check that README links open, Markdown renders correctly, and the SVG diagram displays.
6. Copy the repository URL.

## LinkedIn — launch post
1. Open LinkedIn and start a post.
2. Use the text in `linkedin/01_launch_post_ru.md` or `linkedin/01_launch_post_en.md`.
3. Replace the GitHub placeholder with the real public URL.
4. Attach a concise PDF carousel or a lesson illustration if useful.
5. Preview links and formatting before publishing.
6. Respond to comments and capture useful suggestions for future lessons.

## Repeat for each lesson
1. Publish the full bilingual Markdown lesson and assets to GitHub.
2. Verify links and code before announcing it.
3. Prepare a short LinkedIn post in Russian and English; avoid posting two long duplicate posts back-to-back. Consider separate language posts or one bilingual post depending on audience response.
4. Link directly to the lesson file.
5. Track simple metrics: impressions, meaningful comments, profile visits, repository stars, issues, and forks.

## Important
This package prepares files and instructions only. It does not create a GitHub repository or publish anything to LinkedIn.
